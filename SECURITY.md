# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As the ultimate zero-trust execution engine for AI, we take security extremely seriously.
If you discover a vulnerability in TelosVM (e.g., a sandbox escape in the compiler logic or a bypass in the Semantic Verifier), please **do not** open a public issue. 

Instead, email security@telosvm-compiler.dev. We promise a triage response within 24 hours and a coordinated disclosure process.
